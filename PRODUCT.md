# Product

## Platform

web

## Users

Employees of the company (internal staff), using the assistant as a day-to-day work tool. It is not a public-facing or customer product.

## Product Purpose

"AI Agent" (Sidekick) is an internal AI chat assistant that gives employees access to internal company data and tools from a single conversational interface, instead of switching between separate systems. Core loop: ask a question or pick a suggestion on the home screen → get a cited AI response in a chat thread → the chat is saved to history/sidebar for later.

## Positioning

What separates it from a generic ChatGPT-style chat window: it is wired into the employee's actual working context rather than being a blank chat box.

- **Sourced answers**: chat responses include cited sources (reference chips) rather than unattributed text.
- **Internal tools as first-class entries**: sidebar "Tools" section (Text, Slides, Drafting Tool, Build Deck) surfaces internal tooling alongside chat, not as a separate app.
- **Projects**: conversations and work can be organized into named projects, not just a flat chat list.
- **Daily News**: a standing, schedulable monitoring feature (create a feed with a monitoring prompt, category, frequency, delivery day/time) that pushes automated digests — proactive, not just reactive Q&A.

## Operating Context

- **Sidebar** (collapsible): New chat, search chats (with recent/suggested search dropdown), Daily news, History, Tools, Projects, Chats (history list), user profile, dark-mode toggle.
- **Home screen**: greeting + prompt bar + suggestion chips to start a chat.
- **Chat conversation**: user message + AI response (headings, body text, bullet lists, action row — copy/regenerate/download/read-aloud/thumbs up-down — and cited source chips), prompt bar pinned at the bottom to continue the thread.
- **Prompt bar**: text input with attach ("+" opens Upload file / Add image / Create from template / Start new project / Connect tool), voice input (opens a full-screen listening view with live transcript), send.
- **Daily News**: a dedicated list page (search, category filters, sort, pagination) of monitoring feeds, each createable/editable via a "Create new feed" modal (name, monitoring prompt, category, frequency, delivery days, delivery time).
- **Theming**: light and dark mode, user-toggleable, persists only for the session (no backend yet).

## Capabilities and Constraints

- Built as a React + TypeScript + Vite + Tailwind CSS single-page app (no server-rendered pages, no CMS).
- No real backend yet: chat responses, Daily News feed data, and file "uploads" are static/simulated in the frontend — there is no live LLM call, no persistence across page reloads, and no real authentication/user accounts.
- Deployed to Vercel (auto-deploy from the `main` branch on GitHub).
- Visual source of truth is the Figma file "Sidekick redesign" — this codebase is a design-to-code implementation of that file, extended with real interaction (working inputs, navigation, file attach, voice, dark mode) where Figma only specified static states.

## Brand Commitments

- Product name in the UI is "AI Agent" (internal working name; Figma file calls the design "Sidekick").
- Existing AI-response disclaimer copy (in the chat "Disclaimer" block) states responses are generated by Azure OpenAI over "a curated set of Deloitte content" — this is existing product copy, not something to remove or genericize without being asked.

## Product Principles

1. Chat is not the whole product — internal tools, projects, and Daily News are peers to chat in the sidebar, not buried features.
2. Answers should show their work: cite sources rather than presenting AI output as unattributed fact.
3. Proactive over purely reactive: Daily News lets the assistant surface information on a schedule, not only in response to a typed question.
4. The interface should feel like a real product, not a static mockup — inputs, navigation, attachments, and voice should actually work even though there is no backend yet.
